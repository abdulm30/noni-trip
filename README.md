# Luxury Mystery Trip

GitHub Pages-ready mystery trip website.

## Deploy
1. Upload `index.html` and the entire `assets` folder to the repository root.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main`, and choose `/(root)`.
4. Save and open the published URL.

## Important
Keep the folder structure unchanged. The page loads its CSS from `assets/css/style.css` and JavaScript from `assets/js/script.js`. Hotel photographs are loaded from the existing Costco Travel image URLs when the visitor has internet access.
